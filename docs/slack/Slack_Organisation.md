## Overview
This is a file to describe the slack server utilities to the team.
## Agenda
This canal is for discussing tasks creation and assignment to members of the team
It includes a list which contains all taks created for the project with elements such as :
- **Name**
- **Priority**
- **Description**
- **Assigned to**
- **Deadline**
- **By**
- **Created**
## breaks
This canal is to announce whenever you have a break from active work
It must have a valid reason
## bugs
This canal is to notify, discuss and resolve bugs of the project
It includes a list which contains all bugs registered with elements such as :
- **Name**
- **Danger**
- **Description**
- **By**
- **Created**
- **Modified**
## general
This canal is the basic thread of discussion, used for various purposes.
## ideas
If you have an idea, as small as it can be, you can publish it under this canal to discuss its implementation
## meetings
This canal is for the scheduling of meetings as well as a summary in the form of a MoM
It includes a list which contains all meetings scheduled for the project with elements such as :
- **Name**
- **Date**
- **Hour**
- **Location**
- **Done**
- **MoM**
- **By**
- **Created**
## norms
This canal is to create, discuss and vote for the establishement of norm rules.
All rules under this norm must be followed by all members of the team.
It includes a list of all the rules established for the project, with elements such as :
- **Name**
- **Description**
- **Vote**
- **By**
- **Created**
## trello
This canal is to discuss and resolve issues happening on trello
