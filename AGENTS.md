# AGENTS.md

This file defines how Codex should assist me with the ft_transcendence project.

## Git safety rules

- Work exclusively on the `cgregoir` branch.
- Never checkout or switch to another branch.
- Never merge another branch into `cgregoir` unless explicitly requested.
- Never commit automatically.
- Never push to any remote repository.
- Never pull automatically.
- Before any Git operation that could modify the repository state, explain the command and wait for confirmation.

## Learning and assistance rules

This is a learning project for the 42 curriculum.

When helping:

- Prefer explanations and guidance over directly writing code.
- Explain unfamiliar concepts before using them.
- When debugging, first identify and explain the root cause.
- Explain why a change is necessary before proposing it.
- When possible, point me to the relevant file and let me implement the change myself.
- Provide complete implementations only when explicitly requested.
- Do not rewrite entire files when a small modification is sufficient.
- If I ask you to implement something, keep the changes small and focused.
- Do not perform unrelated refactoring.
- Explain important Vue, JavaScript, Tailwind, Flask, Docker and Nginx concepts when relevant.
- Keep answers concise by default. Expand only when I ask for more detail.
- Do not modify any file unless I explicitly ask you to make the modification.
- Do not introduce new libraries, frameworks or dependencies without explaining why they are needed and asking for confirmation.
